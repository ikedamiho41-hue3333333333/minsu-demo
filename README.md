验证：完整314项领域/渲染/来源检查通过；30问问答—交接—接手—回复30/30通过。浏览器另行检查手机390/320、桌面、地点/路线/活动问答、草稿/上下文恢复、手册30题、商家处置30题与人工闭环；真实业务确认、豆包、后端、真实VR和微信真机仍待完成。

以下为项目既有说明与历史版本。

本仓库仅用于分享可交互演示：VR 看房、房源分享、民宿 AI 管家与本地生活。使用示例数据，AI 回答、人工回复及活动内容为演示；数据保存在各浏览器本地，不提供真实后台或跨设备业务同步。VR 为参考案例。

此版本由已核验的 NAS 静态演示文件生成，调整网页标题，并将内联大图原样抽出为同目录静态资源以加快首屏，保留原有手机布局和交互。公网副本通过 GitHub Pages 托管，NAS 副本继续供局域网使用。

本目录不含真实客户资料、账号口令或 NAS 管理配置。

统一入口：打开站点后默认进入客人端，页面顶部直接切换“客人端／商家端”。分享具体房间给客人的链接仍只呈现客户看房界面。这项调整在本仓库的静态 HTML 中维护，未更新 NAS 或旧 Sites 副本。

## v0.4.1 清欢30问与接待修复

[清欢资料预览入口](https://ikedamiho41-hue3333333333.github.io/minsu-demo/?mobile=1&property=qinghuan-dali&release=20261022-qinghuan1#/guest/home)单独保存30个高频问题及接待指引。真实房源、出租方式、地址和店规尚待确认，没有复制虚构样例的床型、免费停车或入住时间。AI管家提供“常见30问”目录，支持原问、相似问法、复合问题、来源与版本查看，以及本地转人工。

商家回看原客人会话使用只读预览；公开精确问答先于泛房型回答；首页停车入口读取公开说明；多房源工作台汇总同商家待办并在房源卡提示数量。原有浏览器资料和对话保留，仅在缺少清欢入口时补入新资料。

30问初始均为待确认的接待指引。商家可编辑答复并保存草稿；只有明确核实本店适用规则、取消“仍需管家确认”且发布后，才作为已确认答复使用。人工回复不会自动公开。问答与人工咨询仍为本地演示，豆包、真实通知、业务后端和真实VR尚未接入。

## 本地运行与构建

本目录的`src/`是与公网产物配套的可维护源码，`index.html`为构建产物；不要用旧NAS打包脚本覆盖它。

```sh
npm ci
npm test
npm run acceptance
npm run build
npm start
```

预览服务仅监听`127.0.0.1:5296`。构建使用锁定版本的Rolldown，不需要模型密钥。`output/`保存本地检查结果且不提交；浏览器演示数据保存在各浏览器本地。
