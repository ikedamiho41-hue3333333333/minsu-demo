# 民宿工具手机演示原型

本仓库仅用于分享可交互演示：VR 看房、房源分享、民宿 AI 管家与本地生活。使用示例数据，AI 回答、人工回复及活动内容为演示；数据保存在各浏览器本地，不提供真实后台或跨设备业务同步。VR 为参考案例。

此版本由已核验的 NAS 静态演示文件生成，调整网页标题，并将内联大图原样抽出为同目录静态资源以加快首屏，保留原有手机布局和交互。公网副本通过 GitHub Pages 托管，NAS 副本继续供局域网使用。

本目录不含真实客户资料、账号口令或 NAS 管理配置。

统一入口：打开站点后默认进入客人端，页面顶部直接切换“客人端／商家端”。分享具体房间给客人的链接仍只呈现客户看房界面。这项调整在本仓库的静态 HTML 中维护，未更新 NAS 或旧 Sites 副本。
